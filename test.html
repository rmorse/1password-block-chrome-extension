🔒 1Password Blocker Extension Test Page

📋 How to Test:
  1. Right-click anywhere on this page
  2. Look for "🚫 Block 1Password on" in the context menu
  3. You should see hierarchical domain options based on your current URL
  4. Each domain has submenu options for blocking strategies

Test Scenarios

1. Multi-level Subdomain Testing

If you're on sub.sub2.domain.com, you should see:

  • domain.com
  • sub2.domain.com
  • sub.sub2.domain.com

Each with options: "Block this domain only" or "Include all subdomains"

2. Localhost with Ports

If you're on localhost:3000, you should see:

  • localhost
  • localhost:3000 (with port)

This allows blocking specific development servers.

3. Standard Domain

If you're on example.com, you should see:

  • example.com

  • ✅ Port-specific blocking for localhost
  • ✅ Visual indicators for already blocked domains (✓)
